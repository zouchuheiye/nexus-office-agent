# 01 产品蓝图

## 1. 产品定义

枢纽不是新的消息工具，也不是带聊天框的 OA。它是以企业目标为中心、连接组织责任、项目执行、业务流程、会议决策、知识与经营数据的 AI 原生管理操作系统。

产品承诺：让管理者更早看见偏差，让员工减少重复协调，让企业决策可以执行、追踪和复盘。

## 2. 目标用户

| 角色 | 核心任务 | 当前痛点 | 平台价值 |
|---|---|---|---|
| 高管 | 战略、经营、资源配置 | 数据滞后、口径不一、风险发现晚 | 目标—项目—指标贯通，生成有证据的决策准备 |
| 部门经理 | 团队目标、人员、项目、协作 | 信息碎片、追进度耗时、责任模糊 | 自动汇总状态、识别负荷与阻塞、推动闭环 |
| PM/PMO | 计划、依赖、里程碑、风险 | 手工周报、跨团队等待、变更不可追溯 | 从事件中更新项目事实，统一风险与决策记录 |
| 员工 | 执行、沟通、汇报 | 多平台切换、重复录入、上下文丢失 | 统一待办、会议行动项、个人 Agent |
| HR | 组织、岗位、绩效、人才 | 业务贡献证据分散 | 连接目标、项目贡献与发展计划 |
| 财务/行政 | 预算、费用、采购、制度 | 材料不完整、规则核对重复 | 智能预审、异常识别、制度依据引用 |
| IT/安全 | 身份、集成、权限、审计 | 系统烟囱、Shadow AI、越权风险 | 统一连接器、策略、模型、审计与成本治理 |

## 3. 产品原则

- `PR-001` 管理闭环优先：每项功能必须落入目标、责任、执行、反馈、决策或复盘中的至少一环。
- `PR-002` 事实与观点分离：业务事实、Agent 推断、人工结论必须有不同状态和展示。
- `PR-003` 单一责任人：目标、项目、风险、决策和行动项都必须有可追责 Owner。
- `PR-004` 渠道无关：网页、飞书、钉钉、企业微信共享同一业务对象和操作结果。
- `PR-005` 渐进自治：Agent 默认建议和草拟，只有满足策略条件才可确认后执行或自动执行。
- `PR-006` 可解释：任何重要分析必须展示来源、时间、权限范围和不确定性。
- `PR-007` 少打扰：通知按影响、时效、责任和用户偏好合并，禁止三平台重复轰炸。
- `PR-008` 可撤销：平台内部可逆写操作应支持撤销或补偿；不可逆操作必须强化确认。
- `PR-009` 模型原生路由：主 Agent 基于权限化上下文和声明式 Skill/Tool 自主选择行为，禁止以关键词或固定程序替代业务理解。
- `PR-010` 对话即工作入口：主对话与实时任务栏构成第一产品界面，任务发布、个人任务和主动承接必须在同一工作面连续可见。

## 4. 产品能力地图

### 4.1 个人工作空间

- 持久主工作对话，以及“我的、待承接、我发布”实时任务栏。
- 从自然语言目标拆出可验收任务包，支持定向分派或团队公开承接。
- 统一待办、收件箱、日程和关注事项。
- AI 晨报、日总结、周复盘。
- 跨渠道搜索和上下文问答。
- 任务、会议、审批、文档的一站式处理。

### 4.2 战略与经营

- 战略主题、年度目标、季度重点。
- OKR/KPI 混合管理。
- 指标树、经营驾驶舱、异常解释。
- 经营会材料、决策和后续行动。

### 4.3 项目与执行

- 项目组合、项目、里程碑、工作包、任务。
- 风险、问题、依赖、变更和决策。
- 资源容量、预算、交付预测。
- 周报自动草拟与人工确认。

### 4.4 流程与审批

- 表单、条件分支、并行会签、加签、委托。
- SLA、催办、升级和异常处理。
- 制度、预算、历史案例的 AI 预审。
- 人工最终审批与审计。

### 4.5 组织与人才

- 组织、岗位、汇报线、项目虚拟团队。
- 成员目录（员工管理）：管理员可直接新增成员、编辑姓名/邮箱/部门/岗位/是否负责人、软停用（保留历史与审计，不物理删）；写操作需组织成员管理员权限，变更即时同步到任务与经营视图。
- RACI、授权和代理。
- 目标贡献、1:1、绩效事实、人才盘点和成长计划。
- 公平性保护：禁止使用聊天活跃度、在线时长等代理指标直接评价员工。

### 4.6 会议与知识

- 会议准备、纪要、决定、行动项和追踪。
- 文档、制度、FAQ、案例和专家知识。
- 权限感知检索、引用、版本和有效期。
- 决策沿革与制度替代关系。

### 4.7 自动化与 Agent

- 触发器、条件、Agent 节点、人工节点和工具节点。
- 多模型路由、Prompt 版本、工具白名单。
- 运行记录、成本、效果和失败重放。

### 4.8 平台治理

- 租户、身份、组织同步、权限策略。
- 连接器、Secret 引用、Webhook、同步状态。
- 审计、数据分级、保留策略和模型治理。

## 5. 首期范围

### 5.1 必须交付

1. 网页管理平台和响应式员工工作台。
2. 组织、用户、角色、数据范围和审计基础。
3. 目标—项目—风险—决策—行动项的纵向管理闭环。
4. 企业 Agent 对该闭环的检索、分析、草拟和确认后执行。
5. 飞书、钉钉、企业微信统一连接器框架。
6. 三平台机器人消息、身份映射、事件接入、交互卡片或等价消息。
7. 模型、连接器、工作流和审计的管理控制台。
8. 单元、集成、E2E、安全和故障测试。

### 5.2 暂不承诺

- 取代完整 ERP、CRM、财务核算或专业 HRIS。
- 未经平台授权访问全部历史聊天。
- 在没有审批与补偿机制时自动执行高风险业务操作。
- 首期提供通用低代码平台或第三方插件市场。

## 6. 首个业务闭环

“项目风险发现 → 管理决策 → 行动落实 → 追踪复盘”包含：

1. 连接器接收会议、消息、任务和组织变化。
2. 归一化事件进入项目事实流。
3. Agent 发现里程碑偏差、依赖阻塞或资源冲突。
4. 向 Owner 展示证据并生成处置方案。
5. 经理在网页或协同平台卡片中确认。
6. 工作流创建任务、通知责任人并写审计。
7. Agent 追踪期限和执行结果。
8. 周会/经营会生成复盘，决策进入企业知识。

## 7. 成功指标

- 风险平均提前发现时间提升 30% 以上。
- 决策到行动项落地时间减少 40% 以上。
- 跨平台重复录入减少 60% 以上。
- 会议行动项按期闭环率提升 20% 以上。
- Agent 建议引用完整率 ≥ 95%。
- 高风险未确认执行为 0。
- 权限越权读取为 0。
