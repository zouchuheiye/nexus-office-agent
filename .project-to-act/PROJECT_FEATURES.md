### RunManifest 不可变合同

每个 Run 在入队前生成一次 `RunManifest`，后续只允许创建新版本，不允许原地扩权。Manifest 至少包含以下字段，序列化后计算 `manifest_digest` 并由控制面签名；Runner 必须在创建 Pi Runtime、Sandbox 和每次恢复前复验。

| 字段组 | 必填字段 | 实现约束 |
|---|---|---|
| 身份与关联 | `schema_version`、`tenant_id`、`actor_id`、`workspace_id`、`session_id`、`session_version`、`branch_id`、`run_id`、`trace_id` | 全部由服务端生成/解析；任何不一致拒绝执行 |
| Repository | `repository_id`、`provider`、`base_ref`、`base_commit_sha`、`ephemeral_branch`、`credential_lease_ref` | 只保存凭据引用；base SHA 必须在 checkout 后复验 |
| Profile | `profile_id`、`profile_version`、`profile_digest`、`allowed_builtin_tools`、`delegation_policy` | Profile 版本不可变；子 Agent 只能取交集 |
| Resource | `skill_releases[]`、`extension_releases[]`、`package_releases[]`，每项含 `id/version/digest/signature_ref` | 仅 approved 且未 revoked 的精确摘要；顺序规范化后再计算总摘要 |
| MCP/Tool | `tool_bindings[]`，含 `tool_id/schema_digest/risk_level/scope/network_policy_ref` | 不包含 Token/OAuth；执行时仍由 Gateway 重新授权 |
| Model | `model_policy_id/version`、允许 provider/model/region、数据级别、最大上下文/输出、降级顺序 | 不包含 API Key；降级模型也必须预先批准 |
| Sandbox | `sandbox_profile_id/version`、runtime class、基础镜像 digest、CPU/内存/PID/磁盘/时长、只读/可写挂载 | 生产不得声明 virtual/host provider；镜像必须签名 |
| Network | `network_policy_id/version`、默认 deny、允许目的域/端口/协议、DNS 策略、代理引用 | 禁止 CIDR 泛放、Metadata、私网回连和解析后地址漂移 |
| Quota | `quota_policy_id/version`、预留 CPU-seconds、memory、storage、tokens、tool calls、child runs | 入队原子预留；终态对账释放；不可由 Runner 自行上调 |
| Governance | `policy_version`、`data_classification`、`retention_policy_id`、`approval_policy_id`、`audit_policy_id` | 策略不可用、过期或摘要不符即失败关闭 |
| 生命周期 | `created_at`、`expires_at`、`manifest_digest`、`controller_signature` | 过期 Manifest 不可启动/恢复；历史版本永久关联事件 |

### 核心状态机与转换所有者

| 对象 | 状态与允许转换 | 唯一转换所有者 | 并发/恢复约束 |

## 公共 HTTP API 契约

所有路径使用 `/api/v1`；所有写请求重新解析 RequestContext，要求 `Idempotency-Key`，状态迁移要求 `If-Match` 或对象版本。异步创建返回 `202`，响应只含服务端生成的 ID、状态、版本和可轮询/订阅链接。SSE 使用 `Last-Event-ID`，按至少一次投递设计，客户端按 `(session_id, sequence)` 去重。

### API 通用错误合同

| HTTP | 错误类 | 处理约束 |
|---|---|---|
| 400 | `PI_INPUT_INVALID` | Schema/格式错误，不进入命令队列 |
| 401 | `AUTHENTICATION_REQUIRED` | 不泄露资源是否存在 |
| 403 | `PI_PERMISSION_DENIED` / `PI_POLICY_DENIED` | 记录脱敏拒绝审计；不得由客户端重试绕过 |
| 404 | `PI_RESOURCE_NOT_FOUND` | 跨租户和真实不存在使用同一外观 |
| 409 | `PI_VERSION_CONFLICT` / `PI_STATE_CONFLICT` | 返回当前版本和安全重试提示，不自动覆盖 |
| 410 | `PI_CURSOR_OR_ARTIFACT_EXPIRED` | 给出允许的恢复点，不恢复已过期凭据 |
| 422 | `PI_DATA_POLICY_REJECTED` / `PI_MANIFEST_INVALID` | 业务/数据边界拒绝，不降级执行 |
| 423 | `PI_APPROVAL_PENDING` | Run 保持暂停，只有有效决定可恢复 |
| 429 | `PI_QUOTA_EXCEEDED` | 返回限额类别与重试时间，不暴露其他租户用量 |
| 502 | `PI_UPSTREAM_FAILED` | 无副作用调用可按预算重试；有副作用转未知结果 |
| 503 | `PI_RUNTIME_NOT_READY` | 生产不得回退内联 Runner、虚拟沙盒或未批准模型 |
